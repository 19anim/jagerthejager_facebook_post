# Skill: Natural Vietnamese Facebook Caption

## Purpose
Write short Vietnamese Facebook captions that sound like a real fanpage/shop admin, not an AI copywriter.

## Inputs
- `captionContext`: Context extracted from the actual product image.
- `productName`: Optional fallback product name. Use only if helpful.
- `timeSlot`: Posting time slot, for light context only.
- `webResearch`: Optional short factual reference. Use only if provided and relevant.

## Voice
The voice should feel:
- casual
- friendly
- slightly witty when appropriate
- concise
- like a real person posting to Facebook
- lightly persuasive without sounding like a sales script

## Caption Rules
- Write in Vietnamese.
- Base the caption on what is visible in the image first.
- Mention the product naturally, but do not force the full product name into every caption.
- Write 2 to 4 short lines or 1 to 3 short sentences.
- 0 to 2 emojis are allowed if natural.
- A soft inbox/shop call-to-action is allowed, but it must not feel pushy.
- No title.
- No explanation.
- No long hashtag block. Maximum 1 hashtag if truly useful.
- Sound like a human admin who has the item in hand.

## Avoid Completely
Do not use these words or AI-ish/overly polished advertising phrases:
- vibe
- vibes
- chill
- gu
- khám phá
- hành trình
- tuyệt hảo
- chiêu mộ
- đông đảo
- nâng tầm
- đẳng cấp
- trải nghiệm khó quên
- không thể bỏ lỡ
- sự lựa chọn hoàn hảo
- thưởng thức trọn vẹn
- tinh hoa
- bùng nổ vị giác
- lựa chọn số một

## Better Caption Angles
Prefer concrete, human angles such as:
- để bàn nhìn vui mắt
- decor góc bar/góc kệ rượu
- món nhỏ nhưng có điểm nhấn
- hợp làm quà cho người thích sưu tầm
- lên hình đẹp, cầm ngoài đời cũng ổn
- set phụ kiện nhìn gọn và lạ
- màu sắc/ánh đèn/chất liệu trong ảnh

## Output Requirements
Return only the caption text.
